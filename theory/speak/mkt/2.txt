Первый закон термодинамики
Первый закон термодинамики – это закон сохранения энергии в тепловых процессах: количество теплоты, переданной системе, идет на увеличение внутренней энергии системы и работу системы над другими телами Ку = ΔУ + А

Для идеального газа в кодификаторе ЕГЭ приведены следующие формулы величин, входящих в этот закон:

внутренняя энергия одноатомного идеального газа У = (3/2)·(м / μ)·Р·Тэ

элементарная работа А = Пэ·ΔВэ

количество теплоты через удельную теплоемкость Ку = цэ уд·м·ΔТэ
Другие формулы термодинамики идеального газа требуется выводить непосредственно при решении задачи.

Внутренняя энергия
В термодинамике под внутренней энергией тела понимают кинетическую энергию хаотического движения молекул и потенциальную энергию их взаимодействия. Внутренняя энергия идеального газа – это только кинетическая энергия хаотического движения молекул, так как потенциальная энергия взаимодействия молекул считается равной нулю.
У одноатомного идеального газа внутренняя энергия - это кинетическая энергия поступательного движения молекул. Из формул молекулярной физики следует У = Нэ·(3/2)·ка·Тэ = (3/2)·ν·Р·Тэ

Так как внутренняя энергия идеального газа зависит только от температуры, то изменение внутренней энергии определяется только начальной и конечной температурами газа, то есть, изменение внутренней энергии и не зависит от типа процесса. Для одноатомного газа ΔУ = (3/2)·ν·Р·ΔТэ

Работа газа
Простые формулы работы газа существуют только для изобарического процесса А = Пэ·ΔВэ; А = ν·Р·ΔТэ
Для всех остальных процессов работу газа можно найти как площадь фигуры под графиком зависимости давления от объема Пэ(Вэ).
Так как площадь фигуры под графиком у различных процессов разная, то работа газа зависит от типа процесса.

Количество теплоты
Количеством теплоты называют энергию, передаваемую системе от других тел без совершения работы. В термодинамике идеального газа часто используют молярную теплоемкость цэ = μ·цэ уд, тогда формула количества теплоты имеет вид Ку = цэ·ν·ΔТэ
Количество теплоты и молярная теплоемкость зависят от типа процесса. В частности, при изопроцессах используются:
цэ Вэ – молярная теплоемкость при постоянном объеме;
цэ пэ – молярная теплоемкость при постоянном давлении.
При изохорическом процессе работа газа равна нулю, поэтому вся теплота, подводимая к газу, идет на увеличение его внутренней энергии Ку = ΔУ. Из этого равенства следуют формула молярной теплоемкости при постоянном объеме для одноатомного газа цэ Вэ = (3/2)·Р

Так как изменение внутренней энергии не зависит от типа процесса, то формулу изменения внутренней энергии через молярную теплоемкость при постоянном объеме можно использовать для любого процесса ΔУ = цэ Вэ·ν·ΔТэ

При изобарическом процессе теплота, подводимая к газу, идет и на увеличение его внутренней энергии, и на работу газа. Из первого закона термодинамики следует уравнение Майера для молярных теплоемкостей цэ пэ = цэ Вэ + Р

Адиабатический процесс
Адиабатическим называют такой процесс, при котором система полностью теплоизолирована, то есть, не отдает и не получает тепло Ку = 0. При адиабатическом процессе работа совершается за счет убывания внутренней энергии. А так как внутренняя энергия зависит только от температуры, то при расширении газа он охлаждается, а при сжатии – нагревается. А = -ΔУ = -цэ Вэ·ν·ΔТэ

На практике быстрые процессы в газе всегда адиабатические, так как газ не успевает отдать тепло окружающей среде. Медленные же процессы - изотермические, так как температура газа успевает сравняться с окружающей средой.

Пример 1. Температура идеального газа некоторой массы м с молярной массой μ изменяется по закону Тэ = α·Вэ в квадрате. Найдите работу, совершенную газом при увеличении объема от Вэ один до Вэ два. Поглощается или выделяется теплота при таком процессе?
Решение. Зависимость давления газа от его объема найдем из уравнения состояния Пэ = (ν·Р / Вэ)·Тэ = (ν·Р / Вэ)·α·Вэ в квадрате = ν·Р·α·Вэ
Это прямо пропорциональная зависимость, график которой - это прямая, проходящая через начало координат.
Работу газа найдем как площадь фигуры под графиком Пэ(Вэ) – трапеции (произведение полусуммы оснований на высоту) А = (Пэ один + Пэ два)·(Вэ два - Вэ один) / 2 = (ν·Р·α·(Вэ один + Вэ два))·(Вэ два - Вэ один) / 2 = (ν·Р·α / 2)·(Вэ два в квадрате - Вэ один в квадрате)
Так как А > 0; ΔУ > 0, то из первого закона термодинамики Ку = ΔУ + А следует, что Ку > 0. То есть, теплота поглощается газом.

Пример 2. Некоторое количество гелия расширяется: сначала адиабатно, а затем изобарно. Конечная температура газа равна начальной. При адиабатном расширении газ совершил работу 4,5 кДж. Какова работа газа за весь процесс?
Решение. Гелий - одноатомный газ, следовательно цэ Вэ = (3/2)·Р
Процесс 2-3 - это изобарическое расширение А два три = Пэ два·(Вэ три - Вэ два) = ν·Р·(Тэ три - Тэ два)
Процесс 1-2 - это адиабатическое расширение А один два = -ΔУ = -цэ Вэ·ν·(Тэ два - Тэ один) = цэ Вэ·ν·(Тэ один - Тэ два) = 4,5 кДж
Отсюда следует ν·(Тэ один - Тэ два) = А один два / цэ Вэ = 4500 / (1,5·8,31) = 361 моль·К
Так как Тэ три = Тэ один, то А два три = ν·Р·(Тэ один - Тэ два) = 361·8,31 = 3000 Дж = 3 кДж
Работа за весь процесс А = А один два + А два три = 4,5 + 3 = 7,5 кДж

Пример 3. В вакууме закреплен горизонтальный цилиндр с поршнем. В цилиндре находится 0,1 моль гелия. Поршень удерживается упорами и может скользить влево вдоль стенок цилиндра без трения. В поршень попадает пуля массой 10 г, летящая горизонтально со скоростью 400 м/с, и застревает в нем. Температура гелия в момент остановки поршня в крайнем левом положении возрастает на 64 К. Какова масса поршня? Считать, что за время движения поршня газ не успевает обменяться теплом с поршнем и цилиндром.
Решение. Это комплексная задача на механику и термодинамику.

Механика. Разделяем движение на элементарные процессы
а) удар пули - центральный абсолютно неупругий. При ударе сохраняется импульс системы «пуля+поршень», так как внешняя сила давления газа мала, а время удара очень мало м·Вэ ноль = (м + Эм)·У
б) движение поршня после удара. Импульс и энергия системы не сохраняются, но можно записать закон изменения кинетической энергии: изменение кинетической энергии равно работе всех сил, то есть, работе газа 0 - (м + Эм)·У в квадрате / 2 = А газа

Термодинамика. Процесс сжатия газа - адиабатический Ку = 0; ΔУ + А = 0; Отсюда находим работу газа А газа = -ΔУ = -цэ Вэ·ν·ΔТэ = -(3/2)·ν·Р·ΔТэ
Решая полученную систему уравнений, получим массу поршня Эм = (м·Вэ ноль в квадрате) / (3·ν·Р·ΔТэ) - м = (0,01·160000) / (3·0,1·8,31·64) - 0,01 = 1600 / 159,55 - 0,01 ≈ 10 - 0,01 = 9,99 кг ≈ 10 кг

Тепловые двигатели
Циклом называют процесс, при котором система возвращается в исходное состояние. На графике зависимости давления от объема цикл изображается замкнутой кривой. Цикл называют прямым, если процесс на графике идет по часовой стрелке. В прямом цикле работа газа положительна и равна площади фигуры внутри кривой цикла.
Тепловым двигателем называют циклически действующую машину, работающую по прямому циклу и преобразующую тепловую энергию в работу. В тепловом двигателе имеется нагреватель (источник тепловой энергии), рабочее тело (газ, совершающий работу) и холодильник (устройство для охлаждения рабочего тела при его возвращении в исходное состояние).
Теплота Ку один – теплота, передаваемая от нагревателя рабочему телу, частично превращается в работу газа А, а оставшееся |Ку два| отдается холодильнику (величина Ку два - отрицательна) А = Ку один - |Ку два|

КПД теплового двигателя - это отношение работы газа к теплоте, полученной от нагревателя η = А / Ку один = (Ку один - |Ку два|) / Ку один

Цикл Карно - это идеальный цикл, состоящий из 2-х изотерм и 2-х адиабат. Тепловую машину, работающую по циклу Карно, называют идеальной тепловой машиной, так как при данных температурах нагревателя Тэ один и холодильника Тэ два цикл Карно имеет максимальный КПД из всех возможных циклов η макс = (Тэ один - Тэ два) / Тэ один

На практике цикл Карно нереализуем, так как изотерма – это бесконечно медленный процесс, а адиабата – бесконечно быстрый. Цикл Карно используют для оценок верхнего предела КПД тепловых двигателей.

Пример. Цикл теплового двигателя (см. рисунок), проводимый с некоторым количеством идеального одноатомного газа, состоит из двух адиабат (1-2, 3-4) и двух изохор (2-3, 4-1). Найдите КПД этого цикла, если температуры в точках 1, 2, 3 и 4 равны, соответственно, Тэ один = 1000 К, Тэ два = 500 К, Тэ три = 300 К, Тэ четыре = 600 К.
Решение. Это не цикл Карно, поэтому КПД можно найти только по общей формуле η = (Ку один - |Ку два|) / Ку один
Для каждого процесса определим теплоту, сообщаемую газу. Тогда сумма положительных величин теплоты будет равна Ку один, а сумма отрицательных величин по модулю – Ку два.
При адиабатических процессах 1-2 и 3-4: Ку один два = 0; Ку три четыре = 0;
При 2-3 (изохорическое охлаждение) Ку два три = цэ Вэ·ν·(Тэ три - Тэ два) = (3/2)·Р·ν·(300 - 500) = -300·Р·ν
При 4-1 (изохорическое нагревание) Ку четыре один = цэ Вэ·ν·(Тэ один - Тэ четыре) = (3/2)·Р·ν·(1000 - 600) = 600·Р·ν
Тогда: Ку один = Ку четыре один = 600·Р·ν; |Ку два| = -Ку два три = 300·Р·ν
η = (600·Р·ν - 300·Р·ν) / (600·Р·ν) = 0,5 = 50%

Второй закон термодинамики
Реальные термодинамические процессы необратимы. Они самопроизвольно протекают в прямом направлении. Но самопроизвольное возвращение системы в исходное состояние практически невозможно, так как вероятность этого процесса исчезающе мала. Например, газ самопроизвольно расширяется в пустоту, но в исходный объем не вернется никогда - это необратимый процесс.
Второй закон термодинамики следует из необратимости тепловых процессов. Известно его несколько формулировок:

формулировка Кельвина - в циклически действующей тепловой машине невозможен процесс, единственным результатом которого является преобразование в работу всего количества теплоты, полученной от нагревателя;

формулировка Клаузиуса - невозможен процесс, единственным результатом которого является передача теплоты от холодного тела к горячему.
Вечным двигателем 2-го рода называют гипотетическое устройство, которое совершает полезную работу за счет охлаждения окружающей среды. Вечный двигатель 2-го рода создать невозможно: даже если тепловой двигатель будет идеальным, то и тогда КПД этого устройства будет равен нулю, так как нагреватель и холодильник имеют одинаковую температуру - это окружающая среда.

Уравнение теплового баланса
Твердые и жидкие тела практически несжимаемы А = 0, поэтому вся теплота, передаваемая телу, идет на увеличение его внутренней энергии Ку = ΔУ.
При нагревании внутренняя энергия увеличивается за счет увеличения кинетической энергии движения молекул, а при фазовых переходах - за счет увеличения потенциальной энергии их взаимодействия.

нагревание Ку = цэ уд·м·ΔТэ;

плавление Ку = λ·м;

испарение Ку = р·м;

сгорание топлива Ку = ку·м;
В этих формулах используются удельные величины, то есть, величины, рассчитанные на единицу массы тела:
цэ уд - удельная теплоемкость;
λ - удельная теплота плавления;
р - удельная теплота парообразования;
ку - удельная теплота сгорания топлива.
Уравнение теплового баланса – это закон сохранения энергии: в теплоизолированной системе твердых и жидких тел алгебраическая сумма количеств теплоты равна нулю. Другая формулировка – в теплоизолированной системе отдаваемая теплота равна теплоте получаемой. Ку один + Ку два + ... = 0; |Ку отд| = Ку получ

В механических процессах при трении и неупругих ударах выделяется теплота, которая также идет на увеличение внутренней энергии твердых и жидких тел. Количество теплоты можно найти по величине работы сил трения или по уменьшению механической энергии тел при их неупругом ударе.

Пример 1. В калориметр, содержащий 200 г воды при температуре 15°С, добавили 20 г мокрого снега. Температура в калориметре стала равна 10°С. Сколько воды было в снеге?
Решение. Вода в калориметре м один отдает теплоту и охлаждается, а мокрый снег м два получает теплоту, от которой снег тает, а затем вся вода из мокрого снега нагревается до равновесной температуры. Записывая уравнение теплового баланса, получаем цэ·м один·(тэ один - тэ) = λ·(м два - м в) + цэ·м два·(тэ - тэ пл)
Отсюда м в = м два - (цэ·(м один·(тэ один - тэ) - м два·(тэ - тэ пл)) / λ = 0,02 - (4200·(0,2·5 - 0,02·10)) / 330000 = 0,02 - (4200·(1 - 0,2)) / 330000 = 0,02 - (4200·0,8) / 330000 = 0,02 - 0,0102 = 0,0098 кг = 9,8 г

Пример 2. В сосуде находится некоторое количество воды и такое же количество льда в состоянии теплового равновесия. Через сосуд пропускают водяной пар при температуре 100°С. Определите температуру воды в сосуде тэ два, если масса пара, пропущенного через воду, равна первоначальной массе воды. Теплоемкостью сосуда можно пренебречь.
Решение. В данном случае конечное состояние системы неизвестно, поэтому уравнение теплового баланса записать нельзя. Проведем оценку количества теплоты в данных процессах:
Теплота, выделяющаяся при конденсации пара Ку один = Эль·м = 2300·м (кДж);
Теплота, требующаяся для плавления льда Ку два = λ·м = 332·м (кДж);
Теплота, требующаяся для нагревания воды от 0 до 100°С Ку три = цэ·2·м·Δтэ = 4,2·2·м·100 = 840·м (кДж);
Теплоты, выделяющейся при конденсации пара, будет достаточно для плавления льда и нагрева всей воды до 100°С. В конечном состоянии в сосуде будет вода при температуре 100°С.

Пример 3. Чистую воду можно переохладить до -10°С. Если бросить в нее кристаллик льда, то она немедленно начнет замерзать. Какая часть воды замерзнет? Система теплоизолирована.
Решение. Теплота, выделяющаяся при замерзании части воды, идет на нагревание всей воды до температуры ее замерзания. Тогда из уравнения теплового баланса λ·Δм = цэ·м·(тэ пл - тэ)
следует Δм / м = цэ·(тэ пл - тэ) / λ = 4200·(0 - (-10)) / 330000 = 42000 / 330000 ≈ 0,13

Пример 4. При какой скорости пули из свинца она полностью расплавится при ударе о стенку, если 80% ее энергии будет затрачено на нагревание пули? Начальная температура пули 27°С, температура плавления 327°С, удельная теплота плавления свинца 25 кДж/кг, удельная теплоемкость свинца 130 Дж/(кг·К).
Решение. При абсолютно неупругом ударе пули о массивную стенку вся ее кинетическая энергия переходит в теплоту, 80% которой идет на нагревание пули до температуры плавления и плавление всей пули. Поэтому закон сохранения энергии имеет вид 0,8·(м·Вэ в квадрате / 2) = цэ·м·(Тэ пл - Тэ ноль) + λ·м
Отсюда находим Вэ = корень квадратный из (2·(цэ·(Тэ пл - Тэ ноль) + λ) / 0,8) = корень из (2·(130·300 + 25000) / 0,8) = корень из (2·(39000 + 25000) / 0,8) = корень из (2·64000 / 0,8) = корень из (160000) = 400 м/с
